# Сайт Сауле Тураровой: как выложить на Vercel

## Что где лежит

| Что | Файл | Трогать? |
|---|---|---|
| **Сайт** — тексты, цена часа, отзывы | `index.html` | Да, здесь всё, что видят клиенты |
| **Заявки** — ИИ-разбор и уведомление в Telegram | `api/lead.js` | Редко |
| **Оферта** — текст договора для клиентов | `oferta.txt` | Да, это ваш договор |
| **Страница оферты** — чтение, вопрос ИИ-помощнику, кнопка «Принимаю» | `oferta.html` | Нет |
| **Приём акцепта** и вопросы ИИ по оферте | `api/accept.js`, `api/offer-ask.js` | Нет |
| **Логотип NPK** — полный и значок (для визиток, соцсетей, документов) | `logo/npk-logo-full.svg`, `logo/npk-mark.svg` | Нет, это исходники |
| **Настройки Vercel** | `vercel.json`, `package.json`, `package-lock.json` | Нет |
| **Настройки Claude Code** | `.claude/settings.json` | Нет |
| Эта инструкция | `README.md` | По желанию |

Файлы `index.html`, `oferta.html`, `oferta.txt` и папка `api` должны лежать в корне: так их находит Vercel. Не переименовывайте и не переносите их.

Сайт работает и без настройки ключей: клиент заполняет форму и одной кнопкой отправляет заявку вам в WhatsApp. Ключи из шага 3 включают ИИ-разбор и уведомления в Telegram.

## 1. Загрузить файлы в GitHub (5 минут, без программ)

1. Зарегистрируйтесь или войдите на github.com.
2. Нажмите **New repository**, назовите его, например, `saule-site`, и нажмите **Create repository**.
3. На странице репозитория нажмите ссылку **uploading an existing file**.
4. Распакуйте архив и перетащите в окно браузера **всё содержимое** папки: `index.html`, `oferta.html`, `oferta.txt`, `package.json`, `package-lock.json`, `vercel.json`, `README.md` и папки `api` и `logo` целиком.
5. Нажмите **Commit changes**.

## 2. Подключить Vercel

1. Войдите на vercel.com через GitHub.
2. Нажмите **Add New… → Project**, выберите `saule-site` и нажмите **Import**.
3. Ничего не меняйте в настройках и нажмите **Deploy**. Через минуту сайт откроется по адресу вида `saule-site.vercel.app`.

## 3. Включить ИИ-разбор и уведомления (по желанию)

В Vercel откройте проект, затем **Settings → Environment Variables** и добавьте переменные:

| Переменная | Где взять |
|---|---|
| `ANTHROPIC_API_KEY` | console.anthropic.com → API Keys. Разбор оплачивается по тарифу Claude API, это доли доллара за заявку. |
| `TELEGRAM_BOT_TOKEN` | В Telegram напишите @BotFather команду `/newbot` и скопируйте токен. |
| `TELEGRAM_CHAT_ID` | Напишите своему новому боту любое сообщение, затем напишите @userinfobot и скопируйте ваш Id. |
| `ANTHROPIC_MODEL` | Необязательно. По умолчанию используется `claude-sonnet-5`. |

После этого откройте **Deployments**, у последней публикации нажмите **⋯ → Redeploy**.

Отправьте тестовую заявку. В Telegram должно прийти сообщение: слова клиента, срочность, оценка в часах, риски, сроки, которые надо проверить, черновик ответа и кнопка «Написать в WhatsApp».

## 4. Подключить домен

1. В Vercel откройте **Settings → Domains** и добавьте ваш домен (npk-law.kz или тот, что вы купили).
2. Vercel покажет DNS-записи, обычно это `A → 76.76.21.21` для корня и `CNAME www → cname.vercel-dns.com`. Внесите их в панели регистратора домена.
3. Обычно домен начинает работать в течение часа, SSL Vercel выпустит сам.

## Как менять сайт

- **Стоимость часа:** в `index.html` найдите строку `const RATE=null;` и замените `null` на число, например `const RATE=25000;`. На сайте появится цена, а в оценке заявки — сумма.
- **Любые тексты:** откройте файл на GitHub, нажмите на карандаш, исправьте и нажмите **Commit**. Vercel опубликует изменения сам.

- **Отзывы:** в `index.html` найдите `const REVIEWS=[];` и добавьте обезличенные отзывы по образцу из комментария над этой строкой. Удобнее всего сначала обезличить текст в версии сайта внутри Claude (кабинет → раздел «Отзывы»), а потом скопировать результат сюда. Пока список пуст, раздел на сайте не показывается.

## Онлайн-оферта вместо eSign и Documentolog

Страница `/oferta.html` (ссылка «Публичная оферта» внизу сайта) заключает договор на консультации без подписи: клиент читает оферту, может задать вопрос ИИ-помощнику, вводит ФИО и телефон, отмечает два согласия и нажимает **«Принимаю оферту»**. Это акцепт публичной оферты по ГК РК.

Что вы получаете в Telegram (тот же бот, что для заявок):
- сообщение «✍️ Акцепт оферты № …» с именем, телефоном и кнопкой WhatsApp;
- файл `akcept-….txt` — ваш архив: номер, дата и время (Алматы), данные клиента, IP-адрес, браузер, отпечаток SHA-256 и **полный текст оферты в той редакции, которую клиент принял**.

Клиент видит подтверждение с тем же номером и отпечатком и может распечатать его или сохранить в PDF.

**Как включить:**
1. Откройте `oferta.txt`, заполните всё в квадратных скобках `[ ]` и проверьте текст как юрист: это шаблон, не готовый договор.
2. Удалите первую строку, которая начинается со слова `ЧЕРНОВИК`. Пока она есть, страница показывает «текст готовится», а сервер не принимает акцепт.
3. Проверьте, что в Vercel заданы `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (шаг 3). Без них акцепт не принимается: иначе запись некуда сохранить. Для ИИ-помощника нужен `ANTHROPIC_API_KEY`; без него страница работает, помощник просто не отвечает.

**Когда меняете текст оферты:** старые акцепты остаются действительными, у каждого в файле свой текст. Если клиент открыл страницу до изменения, сервер попросит его обновить страницу и прочитать новую редакцию.

**Чего это не заменяет:** квалифицированную ЭЦП (NCALayer, eGov). Документы для суда, нотариуса, госорганов и банков, где закон требует ЭЦП или нотариальную форму, подписывайте как раньше.

## Что осталось в версии внутри Claude

Кабинет с историей заявок, мастер обезличивания кейсов и загрузка сертификатов работают в версии сайта внутри Claude. Когда наберутся опубликованные кейсы и сертификаты, их можно перенести в эту версию как обычные блоки страницы.

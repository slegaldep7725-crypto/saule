# Сайт Saule Turarova: как выложить на Vercel

> Домен npk-law.kz и SEO — см. **DOMAIN-SEO.md**: домены .kz нельзя направлять напрямую на Vercel.

В архиве:
- `index.html` — сам сайт;
- `api/lead.js` — приём заявок: ИИ-разбор и уведомление вам в Telegram;
- `vercel.json`, `package.json` — настройки для Vercel.

Сайт работает и без настройки ключей: клиент заполняет форму и одной кнопкой отправляет заявку вам в WhatsApp. Ключи из шага 3 включают ИИ-разбор и уведомления в Telegram.

## 1. Загрузить файлы в GitHub (5 минут, без программ)

1. Зарегистрируйтесь или войдите на github.com.
2. Нажмите **New repository**, назовите его, например, `saule-site`, и нажмите **Create repository**.
3. На странице репозитория нажмите ссылку **uploading an existing file**.
4. Распакуйте архив и перетащите в окно браузера **всё содержимое** папки: `index.html`, `package.json`, `vercel.json`, `README.md` и папку `api` целиком.
5. Нажмите **Commit changes**.

## 2. Подключить Vercel

1. Войдите на vercel.com через GitHub.
2. Нажмите **Add New… → Project**, выберите `saule-site` и нажмите **Import**.
3. Ничего не меняйте в настройках и нажмите **Deploy**. Через минуту сайт откроется по адресу вида `saule-site.vercel.app`.

## 3. Включить ИИ-разбор и уведомления (по желанию)

В Vercel откройте проект, затем **Settings → Environment Variables** и добавьте переменные:

| Переменная | Где взять |
|---|---|
| `ANTHROPIC_API_KEY` | console.anthropic.com → API Keys. Разбор оплачивается по тарифу Claude API, это доли доллара за заявку. |
| `TELEGRAM_BOT_TOKEN` | В Telegram напишите @BotFather команду `/newbot` и скопируйте токен. |
| `TELEGRAM_CHAT_ID` | Напишите своему новому боту любое сообщение, затем напишите @userinfobot и скопируйте ваш Id. |
| `ANTHROPIC_MODEL` | Необязательно. По умолчанию используется `claude-sonnet-5`. |

После этого откройте **Deployments**, у последней публикации нажмите **⋯ → Redeploy**.

Отправьте тестовую заявку. В Telegram должно прийти сообщение: слова клиента, срочность, оценка в часах, риски, сроки, которые надо проверить, черновик ответа и кнопка «Написать в WhatsApp».

## 4. Подключить домен

1. В Vercel откройте **Settings → Domains** и добавьте ваш домен (npk-law.kz или тот, что вы купили).
2. Vercel покажет DNS-записи, обычно это `A → 76.76.21.21` для корня и `CNAME www → cname.vercel-dns.com`. Внесите их в панели регистратора домена.
3. Обычно домен начинает работать в течение часа, SSL Vercel выпустит сам.

## Как менять сайт

- **Стоимость часа:** в `index.html` найдите строку `const RATE=null;` и замените `null` на число, например `const RATE=25000;`. На сайте появится цена, а в оценке заявки — сумма.
- **Любые тексты:** откройте файл на GitHub, нажмите на карандаш, исправьте и нажмите **Commit**. Vercel опубликует изменения сам.

- **Отзывы:** в `index.html` найдите `const REVIEWS=[];` и добавьте обезличенные отзывы по образцу из комментария над этой строкой. Удобнее всего сначала обезличить текст в версии сайта внутри Claude (кабинет → раздел «Отзывы»), а потом скопировать результат сюда. Пока список пуст, раздел на сайте не показывается.

## Что осталось в версии внутри Claude

Кабинет с историей заявок, мастер обезличивания кейсов и загрузка сертификатов работают в версии сайта внутри Claude. Когда наберутся опубликованные кейсы и сертификаты, их можно перенести в эту версию как обычные блоки страницы.
